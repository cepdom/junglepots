- Two construction views switch the real photograph, alt text, caption and explanatory text without changing the image frame height.
- Colour reference selection updates the finish enquiry email draft; it never recolours a photograph. Digital swatches are indicative.
- Technical questions use native details disclosures; core material facts remain visible.
- Responsive layout uses the same max width, gutters, typography and container breakpoints as the collection index.
- Desktop/mobile review controls are outside the website and should be removed in production.
- Standalone navigation connects the completed pages. Inline review navigation stays within the conversation fragment. This is a design prototype, not a hosted production site.
