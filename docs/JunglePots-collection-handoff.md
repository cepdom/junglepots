# Collection handoff — compact template

The current design supersedes the earlier expanded Big Ben Tower page. See `JunglePots-flexible-collection-template.md` for the shared layout, conditional content rules and multiple-size behaviour. Open `junglepots-big-ben-tower.html` with its adjacent assets and PDF.

This is a responsive HTML design prototype for later React/Tailwind implementation, not a deployed site or connected CMS. The enquiry prepares an email draft and does not send automatically. Gallery, unit and colour selection are local interactions. Related entries are previews. The source data, asset provenance and catalogue analysis remain applicable. The approved homepage and price-free PDF are unchanged.
