# Siena — collection page

The fourth collection page. Built from Siena Kubo, so the comparison schedule,
the per-view frame proportions and the letter-convention disclosure came for
free. Two things make this page worth reading beyond its place in the queue.

---

## 1. The catalogue's capacity column for Siena is wrong

And it can be shown, three ways.

| | 65 | 95 | 95H |
|---|---|---|---|
| Catalogue, page 24 | 7 L | 17 L | 43 L |
| External box (A × B × C) | 87.8 L | 128.3 L | 179.6 L |
| Jungle Flora's own listing | **80 L** | **120 L** | **170 L** |

The listing figures sit at 91 / 94 / 95 % of the external box — which is what
a thin-walled steel trough should give. The catalogue's sit nowhere sensible:
7 L inside an 87.8 L box is 8 %.

And the clincher: **7 / 17 / 43 are exactly Riverside Flow's 200 / 300 / 400
capacities from page 9.** The column looks copied from another collection.

The page publishes **both**, in a capacity table of its own, under the heading
"CAPACITY / TWO SOURCES, TEN TIMES APART", with a disclosure that sets out the
arithmetic and names the Riverside Flow coincidence. It does not pick one
silently and it does not derive a third number.

This is worth raising with JunglePots directly. If the catalogue is wrong here
it may be wrong in the same way elsewhere — Riverside Rise repeating 31 L
across three heights, and Siena Kubo publishing no capacity at all, are the
same family of defect.

## 2. Where the photography comes from — and who owns it

The emedelynas.lt listings name **Jungle Flora as the seller**. It is a
marketplace, and these are the client's own listings carrying their own
studio photography.

That resolves the rights question left open on Tower Bridge. Those frames are
relabelled from "retail listing" to **"Jungle Flora / listing"**, the
provenance file records the seller, and the Tower Bridge handoff's "rights
check outstanding" section is now a resolved one. Still worth a line of
confirmation before publication; no longer an open risk.

Each Siena model is listed separately, and each listing carries the same four
studio frames plus its own isolated shot:

| View | Note |
|---|---|
| 01 Product | isolated trough |
| 02 Three models | all three together — the scale comparison the table cannot give |
| 03 Rim | folded rim, corner, sand-textured coating |
| 04 Foot | an adjustable levelling foot under the corner |

**There is no installed photograph of Siena anywhere.** The three listings all
carry a moss-wall frame — but it shows Siena **Kubo** cubes, not Siena
troughs. It is filler, reused across listings, and using it would have
attributed the wrong product. So the gallery leads with the isolated product,
as the flexible template directs when no project photograph exists, and a
context shot goes on the content-request list.

The rim and foot frames are shot on a grey sweep rather than a white one, so
there is no cutout to be had. They stay photographs, shown full-frame, rather
than being forced into the cutout treatment.

## 3. The drawing

Traced from the listing's isolated photograph, not the catalogue's.

The catalogue crop (page 24) traces to a clean silhouette but recovers no
interior edge at all — the result reads as a flat hexagon rather than a
trough. The listing photograph recovers the **folded rim band** as a thin
parallelogram across the top, which is a real feature and makes the drawing
read as what it is. Straighter edges, too.

So the caption says "Traced from product photography", not "catalogue
photography". Each drawing names what it was traced from; they do not all
have to come from the same place.

A / B / C here are **A length, B depth, C height** — C is the vertical, as on
both towers, but *not* as on Siena Kubo. The note under the schedule says so,
because a reader arriving from the Siena Kubo page is carrying the other
convention.

One drawing serves all three models: the 65 and 95 differ only in length, the
95H only in height.
